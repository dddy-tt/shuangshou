# 智能手语手套小程序设计系统

## 设计原则

产品视觉为“清晰的穿戴设备控制中心”，而不是深色数据大屏。优先级始终是：一眼看懂、操作明确、实时稳定、适度精致。借鉴 Apple HIG 的层级与克制反馈、Material 3 的一致组件和状态语义、微信小程序的原生触控习惯；不复刻任一品牌页面。

## 色彩

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--color-brand` | `#116B5A` | 主操作、品牌锚点 |
| `--color-brand-soft` | `#E4F3EF` | 选中背景、轻强调 |
| `--color-ink` | `#17221F` | 一级文字、核心数字 |
| `--color-text` | `#4C5B56` | 二级文字 |
| `--color-muted` | `#78857F` | 三级/辅助文字 |
| `--color-page` | `#F5F7F5` | 页面背景 |
| `--color-surface` | `#FFFFFF` | 卡片背景 |
| `--color-line` | `#E3E8E5` | 分割线、边框 |
| `--color-success` | `#2D7A58` | 已连接、平直 |
| `--color-warning` | `#AF761C` | 半弯、注意 |
| `--color-danger` | `#B34B48` | 全弯、错误/断开 |
| `--color-info` | `#326C91` | 信息、IMU |

状态色采用降低饱和度的背景与高可读文字；颜色之外必须同时有文案或图标，不依赖色觉判断。

## 排版与间距

- 页面标题 `44rpx`，核心结果 `64rpx`，大数字 `52rpx`，卡片标题 `30rpx`，正文 `28rpx`，辅助文字 `24rpx`，标签 `22rpx`。
- 页面水平边距 `32rpx`；常规卡片内边距 `28rpx`；卡片间距 `20rpx`；小组件间距 `12rpx`。
- 数字使用系统等宽数字优先的系统字体；中文使用系统无衬线字体。禁止混入装饰字体、emoji 作为正式图标。

## 组件规则

- 圆角：小控件 `16rpx`、卡片 `28rpx`、状态胶囊 `999rpx`；不在同一页面混用多种不必要圆角。
- 卡片：白色 surface、`1rpx` 细边线，默认不使用大阴影；需要浮起时仅 `0 8rpx 24rpx rgba(23,34,31,.06)`。
- 主按钮：高度 `88rpx`，品牌色白字；次按钮：浅色填充深字；危险按钮只用于不可逆或安全动作。
- 图标：统一 `32rpx` 线性风格；图标必须配文字。
- 空状态：给出原因和下一步，不用纯空白。
- 状态：由 `StatusBadge` 统一渲染“未开启、扫描中、连接中、订阅中、已连接、重连中、错误、已断开”。

## 动效与性能

- 只为点击、连接状态和数据变化使用 150–220ms 的透明度/位移过渡。
- 不使用持续闪烁、旋转光圈、粒子、玻璃拟态或大面积渐变。
- BLE 帧可高频进入共享状态；页面只以合适节流刷新展示，避免每帧触发整页重排。

## 深浅色策略

本期正式比赛界面固定为浅色，以提高现场可读性。页面不根据系统自动切黑；深色仅作为后续独立主题，必须完整定义所有 token 后才可启用，不能与浅色页混用。

## 页面信息优先级

| 页面 | 第一眼信息 | 主操作 | 应避免 |
| --- | --- | --- | --- |
| 首页 | 设备是否正常、最近识别结果 | 连接设备、进入翻译 | 调试字段堆满首屏 |
| 翻译 | 当前翻译文字、十指实时状态 | 校准、播报 | 管理表单挤占主视图 |
| 手势训练 | 四步流程与当前采样 | 捕获并保存 | 多段说明文字 |
| 手势库 | 手势名称与启用状态 | 搜索、编辑、删除 | 密集原始数据表格 |
| 设置/调试 | 链路状态与原始帧 | 重连、查看日志、校准 | 将演示状态伪装为真机结论 |
